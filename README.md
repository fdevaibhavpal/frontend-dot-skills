# Frontend Dot Skills
Open-source frontend engineering skills for AI coding agents.

A modular collection of reusable skills designed to help AI coding agents build maintainable, accessible, performant, and production-ready frontend applications.

The project aims to bring product thinking, UI/UX, frontend architecture, code quality, and modern development practices into everyday AI-assisted workflows.

✨ Goals
🎨 UI/UX & Design Systems — Design consistency, typography, color, layout, and responsive interfaces.
🏗️ Frontend Architecture — Component design, modularity, maintainability, and refactoring.
🧩 Library Recommendations — Select appropriate UI, animation, and visualization libraries for specific use cases.
🔍 Code Quality — Code review, accessibility, testing, and engineering best practices.
🚀 Performance & SEO — Web performance, search optimization, and production readiness.
🤖 AI Workflows — Reusable prompts, context efficiency, and task-aware agent collaboration.
🛠️ Planned Compatibility

Designed with portability in mind, with integrations planned for:

Claude Code
OpenAI Codex
Cursor
Google Antigravity
Other compatible AI coding agents
⚙️ Technology Approach

The initial architecture is expected to use:

Agent Skills: Markdown-based SKILL.md files and supporting references.
Configuration: JSON and platform-specific plugin manifests where required.
Automation: TypeScript or shell scripts for project inspection and verification.
Distribution: GitHub and platform-compatible skill or plugin packages.

Final implementation choices may evolve during development.

📌 Project Status

Work in Progress. The architecture, initial skills, and platform integrations are being developed. Installation instructions and compatibility details will be published as implementations become available.
